## 🚀 Rêberê Xebitandinê

### 1. Rastdest bi Python re Xebitandin

```bash
pip install -r requirements.txt
python main.py
```

### 2. Çêkirina Serlêdana Standalone (PyInstaller)

```bash
python build.py
```

Serlêdana hatî derxistin dê di peldanka `dist/CyberHealthDesktop` de amade be.
